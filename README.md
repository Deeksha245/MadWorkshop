# MAD Workshop

This repository contains the programs, practical exercises, and project work completed as part of the **Mobile Application Development (MAD) Workshop**.

## Technologies Used

* Flutter
* Dart
* Android Studio / VS Code
* Android SDK

## Project Structure

```text
Workshop/
├── android/
├── ios/
├── lib/
├── test/
├── web/
├── windows/
├── macos/
└── linux/
```

## Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/Deeksha245/MadWorkshop.git
```

### 2. Navigate to the Project

```bash
cd MadWorkshop/Workshop
```

### 3. Install Dependencies

```bash
flutter pub get
```

### 4. Run the Application

```bash
flutter run
```

## Workshop Objectives

* Understand the fundamentals of mobile application development.
* Learn Flutter and Dart programming.
* Develop user interfaces using Flutter widgets.
* Understand application navigation and user interaction.
* Build and test mobile applications.
